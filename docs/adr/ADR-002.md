# ADR-002: Own rule engine on Polars, with import of Great Expectations suites

- **Status:** Accepted
- **Date:** 2026-11-13
- **Decided by:** Trevor Kauyu
- **Source:** Architecture & Design v0.1, section 10

## Context

The method's contribution must be attributable to RAI and measurable against baselines.

## Decision

Own rule engine on Polars, with import of Great Expectations suites.

## Consequences

More code to own and test; the importer keeps adoption easy for teams already using Great Expectations.
