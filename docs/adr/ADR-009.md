# ADR-009: Self-hosted only for the MVP; public read-only demo later

- **Status:** Accepted
- **Date:** 2026-11-13
- **Decided by:** Trevor Kauyu
- **Source:** Architecture & Design v0.1, section 10

## Context

No multi-tenant hosted service before a security review.

## Decision

Self-hosted only for the MVP; public read-only demo later.

## Consequences

Reviewers run RAI locally, which also supports reproducibility.
