# ADR-001: Python 3.12 and FastAPI for all backend components

- **Status:** Accepted
- **Date:** 2026-11-13
- **Decided by:** Trevor Kauyu
- **Source:** Architecture & Design v0.1, section 10

## Context

The platform depends on data and ML libraries; the owner's expertise is Python and SQL; the work aligns with SOC 15-2051; outside reviewers must reproduce it easily.

## Decision

Python 3.12 and FastAPI for all backend components.

## Consequences

Rich validation and TEVV ecosystem. Typing is enforced with mypy strict to compensate for dynamic typing.
