# ADR-006: Apache-2.0, public GitHub repository from day 1, DCO sign-off

- **Status:** Accepted
- **Date:** 2026-11-13
- **Decided by:** Trevor Kauyu
- **Source:** Architecture & Design v0.1, section 10

## Context

Dated public authorship evidence, patent grant and easy adoption.

## Decision

Apache-2.0, public GitHub repository from day 1, DCO sign-off.

## Consequences

All code is public; no secrets, partner data or real customer data may enter the repo.
