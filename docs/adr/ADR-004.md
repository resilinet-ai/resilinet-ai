# ADR-004: React and TypeScript UI; PostgreSQL as the job queue, no message broker

- **Status:** Accepted
- **Date:** 2026-11-13
- **Decided by:** Trevor Kauyu
- **Source:** Architecture & Design v0.1, section 10

## Context

One-person build; few moving parts.

## Decision

React and TypeScript UI; PostgreSQL as the job queue, no message broker.

## Consequences

Queue throughput is ample for the MVP; revisit at multi-tenant scale.
