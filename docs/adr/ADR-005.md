# ADR-005: SandboxBank fraud model is a gradient-boosted classifier on synthetic data

- **Status:** Accepted
- **Date:** 2026-11-13
- **Decided by:** Trevor Kauyu
- **Source:** Architecture & Design v0.1, section 10

## Context

TEVV and drift detection need a real model to test.

## Decision

SandboxBank fraud model is a gradient-boosted classifier on synthetic data.

## Consequences

A model card and the data generator must be published.
