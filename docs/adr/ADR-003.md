# ADR-003: Toxiproxy plus the Docker SDK for fault injection; Kubernetes later

- **Status:** Accepted
- **Date:** 2026-11-13
- **Decided by:** Trevor Kauyu
- **Source:** Architecture & Design v0.1, section 10

## Context

The MVP must run on a laptop with no cluster.

## Decision

Toxiproxy plus the Docker SDK for fault injection; Kubernetes later.

## Consequences

Faults are limited to Compose-level targets; a Chaos Mesh adapter is a year-2 item.
