# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give and accept constructive criticism, and focus on what is best for the project and its users. Harassment and personal attacks are not tolerated.

Report unacceptable behaviour privately to the maintainer through GitHub. Reports are handled confidentially.
